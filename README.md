# ZVUK: Evolving Sound

ZVUK

Build the app under the name ZVUK.

ZVUK is a Bosnian word meaning sound.

The name should be treated as the core identity of the product.

Do not use "KOSMOS" as the app name.

The musical influence is kosmische musik, krautrock, early analog synthesizers, Berlin-school sequencing, ambient electronic music, and vintage electronic sound — but ZVUK itself should feel broader and more timeless.

Brand

The brand should feel:

minimal

European

understated

intelligent

analog

atmospheric

timeless

slightly mysterious

Avoid making the Bosnian origin into a visual stereotype.

Do NOT use:

flags

folk patterns

Balkan clichés

national symbols

excessive cultural references

The Bosnian connection should primarily live in the name itself.

The interface should simply say:

ZVUK

with the meaning of the word becoming something the user discovers.

Tagline

Use a very restrained tagline:

an ever-changing electronic soundscape

Alternative microcopy can use:

sound, in motion

but do not clutter the interface with marketing language.

Visual identity

The ZVUK wordmark should be simple typography.

Prefer:

ZVUK

rather than:

Z V U K

Do not use an elaborate logo initially.

Typography should have:

clean geometric construction

generous spacing

excellent readability

subtle character

no futuristic sci-fi styling

The visual identity should feel equally appropriate on:

a 1970s synthesizer

a modern music application

a cassette

a record sleeve

a contemporary design studio website

Color direction

Use a restrained dark palette.

Primary background:

very dark charcoal / near-black.

Primary text:

warm off-white.

Secondary text:

muted gray.

Accents should be extremely restrained.

Avoid bright neon colors.

Avoid purple/blue "AI" gradients.

Avoid generic startup gradients.

The sound and animation should provide most of the visual interest.

Main interface

The opening screen should be almost empty.

At the top:

ZVUK

Small secondary text:

GENERATIVE SOUND

The majority of the screen should belong to the sound visualization.

The user should immediately understand that this is an instrument, not a dashboard.

Central control:

PLAY

When playing:

PAUSE

Below the main control:

A minimal indication of the current musical state.

For example:

D MINOR · 72 BPM

These values should change gradually as the system evolves.

Visualization

The visualization is a major part of the ZVUK identity.

Do not create a conventional equalizer or waveform.

Instead create a slowly evolving abstract field.

Possible visual elements:

tiny particles

points of light

slow orbital movement

translucent geometric forms

extremely subtle lines

slowly changing density

soft movement responding to musical energy

The animation should be:

slow
organic
minimal
hypnotic

It should never feel like a nightclub visualizer.

The user should be able to stare at it for several minutes without getting tired of it.

The visualization should suggest that something is happening inside the machine.

Sound philosophy

ZVUK creates pleasant, musical, continuously evolving electronic music.

It should never feel like random experimentation for its own sake.

The guiding principle is:

controlled randomness + musical memory + slow evolution

The music should be coherent enough that the listener can relax into it.

But it should change enough that it never becomes an obvious loop.

Musical character

Think:

warm analog oscillators

tape-like instability

slowly moving filters

hypnotic sequencers

spacious delays

large reverbs

modal harmony

subtle pulses

long drones

occasional melodic motifs

slowly changing patterns

Do NOT make the default sound:

piano

music box

lo-fi beat

EDM

techno

glitch

harsh experimental noise

The user should be able to leave ZVUK running for an hour.

Product philosophy

ZVUK should feel less like a synthesizer that the user operates and more like a musical organism that the user steers.

The primary interaction is:

PLAY → LISTEN → ADJUST → MUTATE

Not:

configure 40 synthesizer parameters → create a patch

Keep the complexity underneath the interface.

High-level controls

Expose only musical controls:

SPACE
CLOSE → VAST

MOTION
STILL → EVOLVING

PULSE
DRONE → PULSING

WARMTH
CLEAN → WARM

DENSITY
SPARSE → FULL

HARMONY
SIMPLE → RICH

Use elegant sliders.

Avoid traditional synthesizer knobs unless they genuinely improve the experience.

MUTATE

Include a central secondary action:

MUTATE

It should alter the musical state intelligently.

It should never completely randomize everything.

The listener should recognize continuity.

Think:

"same machine, new direction."

Presets

Keep presets minimal.

Examples:

DEEP
KOSMISCHE
NIGHT
DRIFT
DAWN
SUSPENDED

Presets should feel like moods, not technical patches.

The most important requirement

Do not optimize for the number of features.

Optimize for this experience:

A user opens ZVUK.

They press PLAY.

The room fills with warm, pleasant, slowly evolving electronic music.

They watch the subtle visual field.

Five minutes later the music has changed.

Twenty minutes later it has changed again.

But it still feels like the same piece of music.

The user does not know exactly what changed.

They simply want to keep listening.

That is ZVUK.
